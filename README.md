# Projektarbeit - Gruppe X
Repository zur Dokumentation unserer Projektarbeit in der Berufsschule.

Der Gesamte Projektentwurf ist unter: Projektenwurf.md abgelegt.

## Projektentwurf:
Auf einem Proxmox Server sollen Linux Server sowie Windows Clients virtualisiert werden. 
Folgende Dienste sollen auf den Server betrieben werden:
- Security Information and Event Management (SIEM) mit Wazuh
- PXE Server, Software Deploy- und Management mit OPSI
- Domain Controller und DNS Server mit SAMBA
- DHCP Server mit ISC Kea DHCP
Als Testsysteme werden Virtualisierte- als auch Bare Metal Windows 11 und Linux Maschienen verwendet.

Die Engesetzten Betriebssysteme und Software ist (mit ausnahme von Windows 11)  Open Source und Lizenzfrei.
